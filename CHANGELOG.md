# Changes

## 1.0.5

- Fixed setup when an existing config uses a custom asset-cache folder.
- Added an explicit Windows Python launcher check and clearer setup instructions.
- Gameplay is unchanged; existing 1.0.4 players remain compatible.

## 1.0.4

- Fixed co-op inventory delays and host stuttering caused by queued world/mob updates.
- Added hostile-mob arrival protection and reduced initial world traffic.
- Added lootable TNT and flint and steel, natural TNT outcrops, and TNT blast knockback.
- Crash-site supplies now include three ender pearls and three golden apples.
- Dragon campfire supplies now include two bows and 96 arrows.
- Skeleton arrows remain attached to the hit body part for 90 seconds, visible in co-op.

Close PEAK and rerun setup on the host and all clients to update. Existing saves are retained.
